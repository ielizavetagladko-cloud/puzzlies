# Пазлики / Puzzlies

Ігровий сайт із пазлами: картинки поділені на категорії, частина безкоштовна, решта
відкривається за бали. Бали заробляються грою або купуються пакетами. Пастельний ігровий
стиль, десктоп / планшет / мобільний, українська та англійська мови.

## Запуск

Node.js встановлено локально в `~/.local/node` (без прав адміністратора). Якщо `node` не
знаходиться, додайте його в PATH — рядок уже є в `~/.zshrc`:

```bash
export PATH="$HOME/.local/node/bin:$PATH"
```

Далі:

```bash
npm run dev
```

Сайт відкриється на http://localhost:3000 і перекине на `/uk` або `/en` — залежно від мови
браузера та збереженого вибору.

Інші команди:

```bash
npm run build
```

```bash
npm run lint
```

## Що вже працює

- **Каталог**: 5 категорій, 38 картинок; безкоштовні або за бали.
  Картинки й каталог живуть у Supabase, тож нові зʼявляються без деплою
- **Гра**: власний рушій на `<canvas>` — справжні пазлові шматочки з «замочками»,
  перетягування мишею й пальцем, snap у своє місце, підказка-привид, pinch-zoom і pan
- **Фрагменти**: шматочки зчіплюються між собою будь-де на столі й далі рухаються як одне
  ціле; готовий фрагмент лягає в рамку цілком. Перемішування не розриває зібране
- **Звук**: коротка заставка на старті, клац при зчепленні та переможна фанфара —
  синтезовані через WebAudio, без жодного аудіофайлу
- **Складності**: 12 / 48 / 108 / 300 шматочків
- **Бали**: нагорода за перше проходження + бонус за швидкість, 20% за повтор.
  Для авторизованого гравця їх рахує **база**, а не браузер: функція `complete_puzzle`
  бере складність зі своїх даних і обрізає неправдоподібно швидкий час
- **Розблокування**: за бали, через `unlock_with_points` — з блокуванням рядка профілю,
  щоб два паралельні запити не витратили одні й ті самі бали
- **Акаунт**: гість грає без реєстрації; вхід просимо лише при покупці — просто в діалозі.
  Працює magic link на email і Google; Apple чекає на Apple Developer Program. Показуються
  лише ті способи входу, які **справді увімкнені** в проєкті Supabase
- **Гостьовий прогрес** переноситься в акаунт при першому вході — один раз і зі стелею,
  бо цифри приходять із браузера й перевірити їх неможливо
- **Поповнення балів**: сторінка `/[lang]/points` із пакетами (500 за 89 ₴, 1500 за 219 ₴,
  4000 за 519 ₴). Ціни лежать у базі разом із валютою, не в браузері. Нарахування робить
  `fulfil_order` — функція, яку не може викликати жоден браузерний сеанс, лише вебхук
  провайдера, і яка ідемпотентна, бо провайдери повторюють вебхуки
- **Платежі: WayForPay.** Каса — не посилання, а підписана форма, тому браузер надсилає
  її POST-ом на `secure.wayforpay.com/pay`. Підпис — HMAC-MD5 полів через `;`.
  Гроші підтверджує лише вебхук; повернення покупця на сайт нічого не доводить і лише
  показує те, що вже записано в замовленні. На вебхук треба відповісти підписаним
  «accept», інакше WayForPay повторюватиме його знову й знову
- Тестової заглушки більше немає. Поки мерчант у тестовому режимі, WayForPay сам
  і є тестовим середовищем — тільки чесним, зі справжнім протоколом
- **Незавершені оплати**: якщо покупець пішов зі сторінки WayForPay, не заплативши,
  його зустрічає питання — повернутися до оплати чи скасувати. Замовлення при цьому
  живе в базі, тож видно його і в профілі, з тими самими двома кнопками. Поки діалог
  відкритий, статус перепитується: якщо оплата все ж пройшла, замість питання
  зʼявляється подяка
- **Рейтинг**: `/[lang]/leaderboard` — окрема таблиця для кожної складності, бо середній
  час порівнюваний лише за однакової кількості шматочків. Рахується найкращий час кожної
  картинки; у таблицю потрапляють ті, хто зібрав щонайменше три. Читається через функції
  бази, а не таблиці: чужі рядки закриті RLS, а звідти повертається лише агрегат — без
  пошти й без ідентифікаторів. Хто не задав імені, той «Гравець» плюс шматок хешу
- **Прогрес**: у гостя — у браузері, в акаунта — в базі, з будь-якого пристрою
- **Двомовність**: `/uk` та `/en` з перемикачем, світла й темна теми
- **Пошук**: sitemap, robots, окремі описи й Open Graph-картинки для кожної сторінки
- **Юридичне**: сторінки `/privacy` і `/terms` двома мовами

## Як додати картинки

```bash
npm run images:scan
```

Складіть зображення у `content/incoming/<категорія>/` — теку створить сам скрипт.
`scan` нічого не змінює: він лише читає файли, перевіряє їх і пише чернетку
`content/plan.json`, де вже проставлені здогадки — ідентифікатор, назва з імені
файлу, категорія з теки. Заразом попереджає про те, що зіпсує пазл:

- ширина менша за 1600px — на 300 шматочках картинка розсиплеться в кашу;
- сильно інші пропорції — покаже, скільки відсотків кадру відріже до 4:3;
- нова категорія — нагадає заповнити її назву.

Відредагуйте `plan.json` (назви двома мовами, категорія, `access`: `free` /
`points` / `paid`, ціна, `license`), і застосуйте:

```bash
npm run images:apply
```

Скрипт обріже кожну картинку до 4:3 по найцікавішій частині кадру й стисне до 2400px.

Скрипт сам завантажує файли у сховище Supabase і записує каталог у базу, тож
**картинка зʼявляється на сайті одразу** — ні SQL, ні деплою не потрібно.
Для цього в `.env.local` має бути `SUPABASE_SERVICE_ROLE_KEY`: каталог доступний
на запис лише йому, бо ціни мають лежати там, куди браузер не дотягнеться.

Якщо ключа немає, скрипт це скаже й лишить картинки локально — тоді працює
старий шлях через `npm run seed` і SQL Editor.

## Структура

```
src/
  app/[lang]/            сторінки: головна, категорія, картка пазла, гра, профіль
  components/            UI, картки, ігровий екран
  data/catalog.json      каталог: категорії та пазли (його редагує скрипт)
  data/catalog.ts        типи й пошук по каталогу
  i18n/                  словники uk/en і провайдер
  lib/
    points.ts            складності, формули балів, форматування
    progress.ts          баланс і розблокування: гість — у браузері, акаунт — у базі
    payments/provider.ts місце, куди підключається платіжний провайдер
    catalogue.ts         каталог із бази, з файлом як запасним варіантом
    puzzle/geometry.ts   форма шматочків (безьє «замочки»)
    puzzle/engine.ts     рушій: рендер, drag&snap, зум, збереження
  proxy.ts               редірект на мову
scripts/images.mjs       додавання картинок: обробка, сховище, каталог
content/incoming/        сюди складати нові картинки (поза репозиторієм)
supabase/migrations/     схема, права доступу, сховище
```

## Наступні кроки

1. **Свої картинки.** Демо-набір із Picsum не можна продавати: ліцензія стоку не покриває
   продаж самого зображення. Варіанти — власні чи замовлені ілюстрації, генерація (тоді
   важливі умови конкретного генератора) або відкриті колекції музеїв: там високa
   роздільна здатність, public domain і рівномірна деталізація, яка й потрібна пазлам.
2. **Платні картинки у приватний бакет.** Зараз усі картинки лежать у публічному
   сховищі, а розмиття діє лише в браузері — тобто повне зображення віддається
   будь-кому, хто вгадає адресу. Поки платні картинки демонстраційні, це нічого не
   коштує; перед першим продажем вони мають переїхати в приватний бакет із
   підписаними посиланнями, а публічним лишиться тільки розмите прев'ю.
3. **Валюта.** WayForPay розраховується в гривні, тож ціни в гривні: покупець бачить те
   саме число, яке спишуть. Картка будь-якої країни гривневу суму оплатить — конвертує
   банк покупця. Якщо WayForPay увімкне мультивалютність, перехід на долари — це один
   `update` у `point_packs`, а не зміна коду.
   Про арифметику: комісія «відсоток + фіксована сума» вбиває дрібні покупки, тому
   продаємо пакети балів, а не картинки поштучно.
4. **ПДВ за межами України.** Продаж цифрових товарів споживачам у ЄС формально вимагає
   реєстрації ПДВ незалежно від сум. WayForPay — звичайний еквайр, він цього на себе не
   бере (на відміну від Paddle, який продає як merchant of record). Поки продажі
   українські, питання не стоїть; при виході на ЄС його треба вирішувати окремо.
5. **Своя пошта для листів входу.** Вбудований відправник Supabase має ліміт близько
   3 листів на годину й не годиться для живого сайту. Потрібен Resend або Postmark —
   а для них потрібен власний домен, щоб підтвердити відправника через DNS.
6. **Sign in with Apple**: Apple Developer Program ($99/рік), Services ID, ключ `.p8`.
   Код кнопки вже готовий і зʼявиться сам, щойно провайдер увімкнуть.
7. Дрібниці: PWA-маніфест, шеринг результату, щоденний бонус, синхронізація незавершеної
   дошки між пристроями.

## Про картинки

Частина каталогу — демо-фото з [Lorem Picsum](https://picsum.photos), позначені в базі
як `license: demo`. Їх не можна продавати: ліцензія стоку не покриває продаж самого
зображення. Перед запуском продажів їх варто замінити.

Картини з музейних колекцій (`license: public-domain`) проблеми не мають і для пазлів
підходять навіть краще: висока роздільна здатність і рівномірна деталізація по всьому
полотну, без нудних порожніх зон.
